# Avijit Saha — Portfolio

MERN stack developer & React specialist. A fast, responsive single-page portfolio built with
plain HTML, CSS and JavaScript.

**Live:** https://avijitsaha.netlify.app/

## Sections

- **Hero** — intro, animated role headline, social links
- **About** — background and what I focus on
- **Experience** — timeline of professional work
- **Projects** — five live, open-source builds
- **Skills** — languages, libraries, frameworks and tools
- **Education** — degree and MERN stack training
- **Contact** — phone, email, GitHub and LinkedIn

## Built with

- Semantic HTML5 and custom CSS (custom properties, Grid, glassmorphism, scroll-reveal)
- Vanilla JavaScript for the mobile menu, active navigation, scroll progress and animations
- [Typed.js](https://github.com/mattboldt/typed.js/) for the hero headline
- Google Fonts — Sora and Inter

No build step, no framework, no dependencies to install.

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
